# Bouncing Balls

## What I Implemented

- Implemented a JavaFX animation that displays colored balls moving inside a window.
- Added mouse-click interaction to create a new ball at the clicked position.
- Limited the number of balls to a maximum of 30.
- Stored each ball's radius, color, speed, direction, and velocity as object state.
- Generated a random color and random movement direction for every new ball.
- Updated the balls' positions continuously with a JavaFX `Timeline`.
- Added collision detection between each ball and the four window boundaries.
- Reversed the horizontal or vertical velocity when a ball reaches a boundary.
- Used JavaFX `Circle` objects to draw the balls directly in the scene.

## Overview

This project is a JavaFX implementation of a bouncing-balls animation. The user can click inside the window to create colored balls. Each ball moves independently with a randomly generated speed and direction.

When a ball reaches the left, right, top, or bottom boundary, the corresponding velocity is reversed. The animation continues until the window is closed.

The project demonstrates object-oriented programming, event handling, random values, coordinate-based animation, boundary collision detection, loops, and JavaFX graphics programming.

## Technical Details

### Window and Ball Configuration

The program uses the following fixed configuration:

```java
private static final int BALL_RADIUS = 15;
private static final int WIDTH = 800;
private static final int HEIGHT = 600;
private static final int MAX_BALLS = 30;
```

The scene is created with a width of `800` pixels and a height of `600` pixels. Every ball has a radius of `15` pixels, and at most 30 balls can be added.

### Ball Representation

`Ball` is an inner class that extends JavaFX `Circle`:

```java
class Ball extends Circle {
    private double speed;
    private double direction;
    private double dx;
    private double dy;
}
```

The ball's center position and radius are managed by `Circle`. The additional fields represent its speed, movement direction, and horizontal and vertical velocity components.

The speed is randomly generated between `2` and `10`, and the direction is randomly selected between `0` and `2 * Math.PI`. The velocity components are calculated with:

```java
dx = speed * Math.cos(direction);
dy = speed * Math.sin(direction);
```

### Mouse Interaction

The program listens for `MouseEvent.MOUSE_CLICKED` events on the scene. When the current number of balls is less than `MAX_BALLS`, a new ball is created at the mouse position and added to the pane.

Each ball receives a random RGB color generated by `Color.color()`.

### Movement and Collision Detection

`moveBalls()` is called for every animation update. For each ball, the program:

1. Checks whether the ball's center has reached a horizontal boundary.
2. Reverses `dx` when the left or right boundary is reached.
3. Checks whether the ball's center has reached a vertical boundary.
4. Reverses `dy` when the top or bottom boundary is reached.
5. Updates the ball's center position using `dx` and `dy`.

The radius is included in the boundary checks so that the collision is based on the edge of the complete circle rather than only its center point.

### Animation

The animation uses a JavaFX `Timeline` with a `KeyFrame` every 20 milliseconds:

```java
Timeline animation = new Timeline(
    new KeyFrame(Duration.millis(20), e -> moveBalls())
);
animation.setCycleCount(Timeline.INDEFINITE);
animation.play();
```

The timeline runs continuously and updates every ball's position approximately 50 times per second.

### Environment Requirements

- Java Development Kit (JDK)
- Java compiler (`javac`)
- Java runtime (`java`)
- JavaFX SDK 24.0.1 installed at the path configured in the Makefile
- A graphical desktop environment
- `make` is optional when compiling and running manually

The program uses JavaFX modules including `javafx.controls` and `javafx.graphics`. JavaFX is required; this project does not use AWT or Swing for its graphical interface.

## Usage

After launching the program, an `800 x 600` window titled **Bouncing Balls** opens.

Click anywhere inside the window to create a ball. The new ball immediately begins moving in a random direction with a random color and speed. Continue clicking to add more balls until the maximum of 30 balls is reached.

Close the window to end the animation.

---

## Example

When the user clicks inside the scene, the program creates a ball similar to:

```java
Ball ball = new Ball(
    event.getX(),
    event.getY(),
    BALL_RADIUS,
    Color.color(random.nextDouble(), random.nextDouble(), random.nextDouble())
);
```

During each update, the ball's position changes according to its velocity:

```java
ball.setCenterX(ball.dx + ball.getCenterX());
ball.setCenterY(ball.dy + ball.getCenterY());
```

If the ball reaches a horizontal or vertical boundary, the corresponding velocity changes sign so that the ball moves back into the scene.

---

## Error Handling and Edge Cases

The program handles the following cases:

- Balls reaching the left, right, top, or bottom boundary.
- Positive and negative horizontal or vertical velocity values.
- Random movement directions, including mostly horizontal or mostly vertical movement.
- Preventing the creation of more than 30 balls.
- Closing the JavaFX window to end the application.

### Current Limitations

- The program does not implement ball-to-ball collision physics.
- Balls may be created partly outside the scene if the user clicks close to an edge.
- The program reverses velocity at a boundary but does not clamp the ball's position back inside the scene.
- The application requires JavaFX SDK configuration and cannot run with only the standard JDK libraries.

# Bouncing Balls 彈跳小球

## 實作內容

- 使用 JavaFX 製作多顆彩色小球在視窗中移動的動畫。
- 使用滑鼠點擊事件，在點擊位置建立新的小球。
- 限制最多建立 30 顆小球。
- 儲存每顆小球的半徑、顏色、速度、方向，以及水平與垂直速度。

## 專案簡介

本專案使用 JavaFX 製作彈跳小球動畫。使用者可以點擊視窗，在點擊的位置建立彩色小球。每顆小球都會以隨機產生的速度與方向獨立移動。

當小球碰到左、右、上或下邊界時，程式會反轉相對應的速度，使小球返回視窗內繼續移動，直到視窗被關閉為止。

這個專案展示物件導向程式設計、繼承、滑鼠事件處理、亂數、座標動畫、邊界碰撞判定、迴圈、條件判斷與 JavaFX 圖形繪製。

## 技術細節

### 視窗與小球設定

```java
private static final int BALL_RADIUS = 15;
private static final int WIDTH = 800;
private static final int HEIGHT = 600;
private static final int MAX_BALLS = 30;
```

視窗大小為 `800 x 600`，每顆小球的半徑為 `15`，最多可以建立 30 顆小球。

### 小球資料表示

`Ball` 是繼承 JavaFX `Circle` 的內部類別。小球的圓心位置與半徑由 `Circle` 管理，另外保存速度、方向，以及水平與垂直速度等資料。

速度會在 `2` 到 `10` 之間隨機產生，方向則會在 `0` 到 `2 * Math.PI` 之間隨機產生：

```java
dx = speed * Math.cos(direction);
dy = speed * Math.sin(direction);
```

### 滑鼠操作

程式監聽場景的 `MouseEvent.MOUSE_CLICKED` 事件。只要目前小球數量少於 30 顆，使用者每點擊一次，就會在滑鼠位置建立一顆新小球，並加入 `Pane` 中。

每顆小球都會使用 `Color.color()` 產生隨機 RGB 顏色。

### 移動與碰撞判定

`moveBalls()` 會在每次動畫更新時執行。程式會逐顆檢查小球是否碰到水平或垂直邊界，碰撞時反轉 `dx` 或 `dy`，再更新小球的圓心位置。

邊界判定會使用小球半徑，因此判定的是完整圓形的邊緣，而不是只有圓心位置。

### 動畫

程式使用 JavaFX `Timeline`，每 20 毫秒呼叫一次 `moveBalls()`，大約每秒更新 50 次畫面：

```java
Timeline animation = new Timeline(
    new KeyFrame(Duration.millis(20), e -> moveBalls())
);
animation.setCycleCount(Timeline.INDEFINITE);
animation.play();
```

## 例外情況與限制

程式會處理以下情況：

- 小球碰到左、右、上、下邊界。
- 水平或垂直速度為正值或負值。
- 小球以隨機方向移動，包括接近水平或垂直的方向。
- 防止建立超過 30 顆小球。
- 關閉 JavaFX 視窗以結束程式。

目前的限制如下：

- 尚未實作小球與小球之間的碰撞物理效果。
- 如果點擊靠近視窗邊緣的位置，小球可能會有一部分在場景外。
- 碰撞時只會反轉速度，不會將小球位置強制限制回場景範圍內。
- 程式需要設定 JavaFX SDK，不能只使用標準 JDK 函式庫執行。
